1. INTRODUÇÃO
================================================================

PIX Multi é um aplicativo profissional para geração de QR Codes
PIX válidos pelo Banco Central do Brasil.

FUNCIONALIDADES PRINCIPAIS:
- QR Code PIX 100% válido
- Aceita CPF, CNPJ e todos os tipos de chave
- Múltiplas contas salvas
- Valor com vírgula automática
- Countdown de 2 minutos
- "Copiar e Cola" funcional
- Temas personalizáveis (Premium)
- Logo no QR Code (Premium)
- Multi-contas (Premium)

PÚBLICO-ALVO:
- Pessoas Físicas (CPF)
- MEI (Microempreendedor Individual)
- Empresas (CNPJ)
- Autônomos e Profissionais Liberais
- Lojas e Comércios
- Prestadores de Serviço

6. GERAR QR CODE PIX
================================================================

PASSO A PASSO:
1. Preencha Chave PIX e Nome
2. (Opcional) Preencha Cidade e Valor
3. Toque em "GERAR QR CODE"
4. QR Code aparece na tela
5. Countdown inicia (2 minutos)
6. Use o QR Code ou copie o "Copiar e Cola"

COUNTDOWN DE EXPIRAÇÃO:
- O QR Code expira em 2 minutos por segurança
- Quando expirar, o QR Code some
- O campo Valor é limpo automaticamente
- Gere um novo QR Code para continuar

COPIAR E COLA:
1. Toque em "COPIAR 'COPIAR E COLA'"
2. Mensagem: "Copiado!"
3. Cole no app do banco ou WhatsApp
4. O pagamento é processado normalmente

9. LOGO NO QR CODE (PREMIUM)
================================================================

OPÇÕES DISPONÍVEIS:
- Sem logo: QR Code limpo
- Logo padrão: "PIX" verde
- Iniciais: Suas iniciais (ex: JS)
- Upload: Sua logo personalizada

COMO CONFIGURAR:
1. Toque em (Configurações)
2. Role até "Logo no QR Code"
3. Selecione a opção desejada
4. Para Upload:
   - Toque em "Upload Personalizado"
   - Escolha "Galeria" ou "Câmera"
   - Selecione a imagem

5. Volte para Home e gere QR Code
6. Logo aparece no centro do QR Code

REQUISITOS PARA UPLOAD:
- Formato: PNG ou JPG
- Tamanho: Até 400x400 pixels
- Fundo: Transparente (PNG) recomendado

12. SOLUÇÃO DE PROBLEMAS
================================================================

PROBLEMA: App não abre
SOLUÇÃO:
1. Reinicie o celular
2. Verifique se há atualizações
3. Desinstale e instale novamente
4. Contate o suporte

PROBLEMA: QR Code não é lido
SOLUÇÃO:
1. Aumente o brilho da tela
2. Limpe a câmera do celular que vai ler
3. Aproxime mais o QR Code
4. Gere um novo QR Code

PROBLEMA: Código Premium não ativa
SOLUÇÃO:
1. Verifique o formato: ACT-W-ABC123
2. Use letras MAIÚSCULAS
3. Verifique se não há espaços
4. Contate o suporte

PROBLEMA: Logo não aparece
SOLUÇÃO:
1. Verifique se é usuário Premium
2. Use imagem PNG com fundo transparente
3. Redimensione para 200x200 pixels

14. FAQ - PERGUNTAS FREQUENTES
================================================================

Aceita chave PIX CNPJ?
Sim! O app aceita todos os tipos de chave PIX:
- CPF (pessoa física)
- CNPJ (pessoa jurídica/empresas)
- Email
- Telefone
- Chave Aleatória

Ideal para empresas, MEI, autônomos e profissionais liberais!

O app é grátis?
Sim! A versão Free é completamente funcional.
O Premium é opcional e desbloqueia recursos extras.

Preciso de internet para usar?
Não! O app funciona offline.
Internet é necessária apenas para:
- Ativação Premium
- Doações via PIX

O QR Code é válido em todos os bancos?
Sim! O QR Code segue o padrão do Banco Central
e funciona em todos os bancos brasileiros.

Posso usar em mais de um celular?
Sim! Cada celular precisa de:
- Instalação própria do app
- Login próprio (Free)
- Ou Premium próprio (ou compartilhado)

Como recebo atualizações?
- Baixe a nova versão do mesmo local
- Instale por cima da versão antiga
- Suas configurações são mantidas

Meus dados estão seguros?
Sim! O app:
- Não coleta dados pessoais
- Não usa internet para gerar QR Code
- Salva configurações apenas no seu celular
